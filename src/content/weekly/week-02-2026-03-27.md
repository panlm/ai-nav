# 🤖 AI 工具周报 #2 | 2026.03.20 — 03.26

## 🆕 本周值得关注的 5 个工具/更新

### 1. Cursor Composer 2 — 实力很强，但信任翻车 🔥

Cursor 本周发布了 Composer 2，号称自研编程模型，Terminal-Bench 2.0 得分 61.7%。然而上线不到 24 小时，开发者在 API 调试时发现返回的 model ID 是 `kimi-k2p5-rl-0317`——这是中国 AI 公司 Moonshot AI 的开源模型 Kimi 2.5。

TechCrunch 确认报道后，Reddit 炸锅。Cursor CEO 回应称"使用符合授权条款"，但 Moonshot 预训练负责人公开质疑。推特相关帖子超过 44 万次浏览。

**为什么重要：** 这不只是一次 PR 事故。它暴露了一个行业问题——你付费使用的 AI 工具，底层模型到底是谁的？当 $10B 估值建立在别人的开源模型上，"自研"和"套壳"的边界在哪？

**站内相关：** [Cursor](/tool/cursor)

---

### 2. Google Stitch 大更新 — 免费 AI 设计工具正式挑战 Figma

Google 3/19 更新了 Stitch，加入无限画布、语音交互、设计 Agent 和 MCP Server 集成。Google 官方称之为「vibe design」——用自然语言描述你想要的界面，AI 直接生成。

Business Insider 报道 Figma 股价因此下跌。20 分钟出一个高保真 UI 原型，而且完全免费。

**为什么重要：** 设计工具的 AI 化不是"未来趋势"，是"现在进行时"。对于独立开发者和小团队，Stitch 可能让你彻底跳过"找设计师"这一步。

---

### 3. OpenAI 超级 App — ChatGPT + Codex + Atlas 三合一

WSJ 和 CNBC 3/19 报道，OpenAI 正在将 ChatGPT、Codex 编程工具和 Atlas 浏览器合并为一个桌面「超级 App」。同时计划年底将员工翻倍到 8000 人。

**为什么重要：** OpenAI 的策略越来越清晰——做大到不可替代，像微信一样把所有功能装进一个 App。但另一种声音说：专精工具（Cursor 做编程、Perplexity 做搜索）在各自领域比"什么都做"的超级 App 更好用。你选哪边？

**站内相关：** [ChatGPT](/tool/chatgpt)

### 4. Visa "Agentic Ready" — AI Agent 终于可以刷卡了

Visa 本月在欧洲 21 家银行和发行商上线了 Agentic Ready 计划。这意味着 AI Agent 可以直接发起支付交易——不需要人类中间操作。

**为什么重要：** AI Agent 从"帮你查信息"进化到"帮你花钱"，这是商业化路径上的里程碑。当 Agent 能支付，它就不只是助手，而是代理人。工具选型从"功能"维度扩展到了"交易能力"维度。

---

### 5. AI 编程工具安全审计 — 22,511 个插件被扫描

The New Stack 发布了一份重磅安全审计报告，对 Cursor、Claude Code、Windsurf 等主流 AI 编程工具的 22,511 个 skills/extensions 进行了安全扫描，发现大量潜在安全隐患。

**为什么重要：** 我们关心工具好不好用，但很少问"安不安全"。当你让 AI 访问你的代码库、数据库、API 密钥时，插件生态的安全性直接关系到你的项目安全。

## 🔴 本周关停/重大变更

### 🔴 OpenAI 关停 Sora 视频平台

3 月 24 日，OpenAI 宣布关停 Sora——上线仅 3 个多月的 AI 视频生成平台。NYT、WSJ、TechCrunch 集中报道。迪士尼紧急撤回原计划的 10 亿美元合作。原因：计算成本极高，付费转化远低于预期。OpenAI 选择聚焦 ChatGPT 超级 App。

**影响：** 百万级用户需要迁移。我们整理了 [5 个最佳替代工具对比](/articles/sora-alternatives)，帮你快速找到替代方案。

### ✊ #QuitGPT 运动持续扩大

自 OpenAI 2 月底签署 Pentagon 军方合同以来，已有 **250 万用户** 取消订阅或卸载 ChatGPT。Guardian、France24、Fox News 等主流媒体持续报道。与此同时，OpenAI 在免费版和 Go 版（$8/月）中加入了广告。

Claude 在 #QuitGPT 运动后一度登顶美区 App Store 下载榜。

### ⚠️ Anthropic 被认定为军事供应链风险

Pentagon 将 Anthropic 认定为军事"供应链风险"（supply chain risk），Anthropic 正在联邦法院挑战这一认定。微软出面为 Anthropic 辩护。

## 💡 编辑观点：信任，是选工具的新维度

这周的新闻看似分散，但有一条暗线把它们串在了一起：**信任**。

Cursor 精心包装了发布会，唯独忘了改 API 返回的 model ID——技术信任崩了。OpenAI 签军方合同、加广告、做超级 App——250 万用户用脚投票，价值观信任崩了。22,511 个插件被安全审计发现大量隐患——安全信任也在摇晃。

2025 年，我们选 AI 工具看的是功能和价格。2026 年，多了一个维度：**这家公司值得信任吗？**

- 模型从哪来？是自研还是套壳？
- 我的数据去哪了？安全吗？
- 公司的商业决策，是和用户站在一起，还是和军方站在一起？

这些问题没有标准答案，但作为一个帮你选工具的导航站，我们认为：**透明度本身就是产品力的一部分。** 未来我们会在工具页面标注模型来源和数据政策，让你做出更知情的选择。
